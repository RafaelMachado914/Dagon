<h1>DAGON</h1>

<P>Jogo de cartas baseado nos contos de lovecraft, onde cada carta possui uma habilidade propria. o é finalizar a rodada com mais vida que o oponente, ganha quem vencer 5 rodadas primeiro. o projeto é feito 100% usando somente java e swing.</P>
